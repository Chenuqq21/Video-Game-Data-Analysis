# Global Video Game Sales Analysis (1980-2020)

## 1. Problem Definition
**Target Audience:** Indie game developers and marketing analysts.
**Analytical Problem:** Which platforms and genres have historically dominated the market? This project aims to identify the most "profitable" combinations to help developers decide where to invest their resources.

## 2. Dataset Description
- **Source:** Kaggle (Video Game Sales)
- **Accessed Date:** April 20, 2026
- **Context:** This dataset contains a list of games with sales greater than 100,000 copies, covering platforms like PS4, Xbox, and Nintendo.
